## How to Run a Program

1.  Install Python 3 if it is not already installed.

2.  Copy the source code for the program you want to run into a `.py`
    file, for example, `program1.py`.

3.  Open a terminal or command prompt in the folder containing the file.

4.  Run the program:

    ``` bash
    python program1.py
    ```

    On some systems, you may need to use:

    ``` bash
    python3 program1.py
    ```

5.  Enter the requested values when prompted and review the output.
